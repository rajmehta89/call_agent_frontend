# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Internal call agents and workspace administrators operating an inbound-call CRM.

## Product Purpose

RelayDesk brings inbound Voice AI, WhatsApp conversations, lead management, shared AI knowledge, and connected commerce data into one operational workspace. The dashboard helps the team see customer activity and outcomes at a glance.

## Operating Context

Users work from a desktop-first browser interface while handling calls, reviewing conversations, following leads, and maintaining the AI agent's knowledge and integrations.

## Capabilities and Constraints

- Existing product areas: Voice AI, WhatsApp, calls, leads, knowledge and Shopify integration.
- The dashboard reads real API data and supports date-range and channel filtering.
- Preserve the existing routes, data integrations, and operational terminology.
- Existing Next.js / TypeScript / Tailwind codebase.

## Brand Commitments

The product name is RelayDesk. The requested direction is a polished, comprehensive operational dashboard while retaining the current product capabilities.

## Evidence on Hand

The repository contains live dashboard components, application routes, and API-connected dashboard data. No separately supplied brand kit, approved imagery, customer claims, or benchmark data is available.

## Product Principles

- Put active customer operations ahead of decorative reporting.
- Make cross-channel performance and follow-up work easy to scan.
- Keep AI automation connected to the underlying calls, conversations, and leads.
- Preserve familiar workflows while improving clarity and hierarchy.
